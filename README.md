## Prerequisites

A running Kubernetes cluster with `kubectl` connected to it. Quickstart with k3d:

```bash
curl -s https://raw.githubusercontent.com/k3d-io/k3d/main/install.sh | bash
k3d cluster create
kubectl cluster-info
```
